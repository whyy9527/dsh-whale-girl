# 魔兽世界：无限的自动攻略与可选数据桥

默认开启顶部细彩条，传输当前任务与位置，供鲸鱼娘主动查攻略。
没有可用彩条时，操作系统确认 Forever 在前台后，
鲸鱼娘将清晰可读的任务名、NPC、区域交给同一 DSH 会话，主动调用无限图鉴的
只读查询；无需用户先输入问题。没有第二套记忆，也不启动另一个 agent。
屏幕读不出的任务、坐标、进度保持未知，不能把图像识别称作游戏内部实时数据直连。

`addons/WhaleBridge` 是已安装的可选游戏内 Lua 数据桥。普通插件没有直接向本地
DSH 发 HTTP 的接口，保存变量也只在重载或退出时落盘。当前数据桥的连续输出
依赖可见像素，按用户选择默认开启；没有实现不可见的连续结构化数据出口。
彩条只绘制已使用的格子，不绘制占位黑底。

## 本机安装

```bash
.venv/bin/python scripts/install-wow.py
```

默认客户端为 `/Applications/World of Warcraft/_forever_`。首次新增插件后，
完全退出并重新启动游戏，在插件列表启用 **Whale Bridge**。之后照常启动 `dsh web`。
后续只更新 Lua 文件时，在游戏里输入 `/reload` 即可应用。
更新后输入 `/reload` 会默认开启细彩条；当前运行中的旧版本也可用 `/whale on` 立即开启。
正常自动攻略只需游戏窗口可见、桌宠有屏幕录制权限，不需要开启像素传输。
`/whale off` 可停用，`/whale on` 重新开启。
移除客户端 `Interface/AddOns/WhaleBridge`
即可卸载；不修改其他插件、账号设置或存档。

## 数据与行为

开启像素桥时，插件每秒更新区域、子区域、UI 地图 ID、坐标、等级/职业、任务 ID 与完成状态、
选中任务及其目标文字、目标 NPC ID/名称。没有账号、角色名、聊天、背包或战斗数值。
任务资料过长时先省略目标文字，再减少任务条目，并标记 `truncated`；缺失不代表没有。
选中任务不自动等于用户意图，客户端 UI 地图 ID 也不等于攻略库的区域 ID。

战斗中仅传版本、采样时间和战斗标记，不读取或输出任务、位置和目标。
secret 值直接省略，不转换成普通数据。API 失败会发出错误状态。
解码失败、遮挡、游戏最小化或快照超过 5 秒时没有当前快照；不会沿用旧坐标。
文字发送时会额外尝试读取一次当前可见面板，即使自动陪看已暂停；不会向模型附加
这次读取的整屏图片。已接收的数据随 DSH 原生会话保存，不能承诺退出即删除历史。

自动采样在任务列表/完成状态、选中任务目标进度、子区域或 UI 地图发生变化时，可以用一张当前画面
触发观察，不必等完整拼图。首次读到有效任务，或游戏进入前台时也主动分析。
等待攻略服务就绪后再处理首次任务；移动坐标与切换目标 NPC 不单独触发，
仍遵守暂停和既有最小发送间隔。其他画面默认攒四张有效变化，组成四宫格。
触发观察不保证开口，模型仍可返回空串。有效非战斗任务轮主动用无限图鉴的
`quests`、`npcs`、`atlas` 查任务、NPC 和地图，无需先打字问；精确工具白名单
同时在模型 schema 与 native guard 执行，不开放其他工具或自动批准操作。
优先复用同任务/版本的静态资料，缺少关键线索再补查，按完成状态区分接取、
任务目标和交付点，避免反复提醒。坐标必须核对地图和单位，不报告实时距离。
查询完成后再读取数据条，任务/区域改变、进入战斗或无法读取时不播放旧提示，
查询结果仍保留在共享 DSH 历史供后续使用。没有数据桥时，游戏前台画面仍可按
可见任务文字查询同样三个工具，静态查询不需要先确认玩家是否已完成任务；
查到资料仍可保持沉默。结果回来时再次检查游戏是否在前台；已切出则不插话。
这种模式无法精确检测查询期间未显示的任务或位置变化，不报告实时距离或保证即时导航。
既无任务快照也无游戏前台来源的普通观察保持零工具。

## 线路与验证

`Protocol.lua` 定义 `WGB1`：14 字节头（magic、big-endian uint16 UTF-8 JSON 长度、
uint32 sequence、uint32 Adler-32）后接 JSON，最多 1400 字节。
细条最多 128×16 格，每格 2 个 UI 单位，只显示实际使用的部分；
前 8 格定位，64 格完整颜色查表校准，
其余每格 RGB 各 2 bit。完整查表也处理 macOS 颜色管理造成的跨通道变换，
灰阶校准不能覆盖这种情况。不是所有 HDR、缩放和遮挡
组合都已验证。定位标记用于测量非整数像素间距，避免客户端缩放时逐格累积偏移。
`app/game.py` 必须在缩放/JPEG/拼图之前读取它。

```bash
uv run --no-sync --with lupa==2.6 python tests/smoke_wow_wire.py --capture
.venv/bin/python tests/smoke_auto_guide.py
```

该检查执行实际 Lua producer，用合成 API 验证中文转义、NPC ID、坐标、secret 省略、
战斗清空，再把数据面板绘制成独立 Cocoa 窗口，验证真实 Quartz 回读。
这不替代客户端内验证：安装后要确认插件加载、非战斗区域和任务变化、进入战斗、
遮挡面板和切换窗口的实际表现。目标本机客户端为 1.60.1.70862，TOC 16001。
